## 진행 상태 요약 (2026-11-23, 3단계 마무리)

상태 어휘는 `미착수`·`진행 중`·`검증 완료`·`보류`다(`mail-sending.md`의 "용어와 진행 상태"). 이 표는 RQ별 상태를 요약한 것이고 기준은 각 RQ의 수용 조건 체크다. 검증 완료 22건, 진행 중 10건, 미착수 0건, 보류 0건이다.

근거로 쓴 실행 결과는 단위 376건(`pnpm test`, 2026-11-23 최종 마무리 실행), 통합 199건(`pnpm test:integration`, 같은 실행, 실제 PostgreSQL과 로컬 `smtp-server`)이고 실패는 0건이다. `pnpm test:nfs` 31건(같은 호스트 NFS loopback, NFSv4.1·4.2 각각)과 볼륨 스크립트 7항목(`scripts/volume/`, a~g)은 직전 3단계 마무리 실행 값이다. NFS 환경이 정리돼 이번에는 실행하지 않았다. 컨테이너 스크립트(`scripts/container/`)는 SIGKILL 중복 발송과 SIGTERM 종료를 각 1회 실행해 기대와 일치했다. `검증 완료`는 로컬 SMTP 서버와 PostgreSQL 기준이다.

## 전체 미검증 목록

- 실제 Gmail·Workspace SMTP(RQ-005·006·009).
- 실제 NAS 제품과 그 서버 재시작·failover(RQ-002·024). 같은 호스트 loopback만 확인했다.
- CI 러너. NFS 테스트와 볼륨 스크립트는 CI에 연결하지 않았다.
- 실제 Gmail의 `Message-ID` 중복 처리(RQ-013). SIGKILL 재발송은 로컬 가짜 SMTP로 관찰했다.
- 컨테이너 재생성과 PostgreSQL 컨테이너 재시작(RQ-026), `NODE_ENV=development` 컨테이너(RQ-025). 운영 구성 기동·SIGTERM·SIGKILL은 로컬 가짜 SMTP로 관찰했다.
- 호스트 외 환경: bind mount, rootless Docker, Docker Desktop·macOS·Windows, ACL 미지원 파일시스템, 호출처가 Linux가 아닌 환경.
- Java 사용처 구현과 JOSE 상호 운용(RQ-021·022).
